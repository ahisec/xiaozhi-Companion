# 伴侣 Android 试用版 0.1.4

适用于原版 M5Stack Cardputer（非 ADV）搭配小米 8。手机原生运行 MCP 连接、后台相机、按需抓拍和视觉接口请求，不需要电脑桥接，不需要修改现有 M5 固件。最低 Android 8.0 / API 26。

## 0.1.4 更新

- “看世界”页新增前置 / 后置摄像头切换，显示当前选择和相机运行状态；自动记住选择，后台抓拍使用同一摄像头。相机开启时切换会自动重开所选镜头。
- 按设备报告选择前后镜头，不假设镜头 ID；缺少所选镜头时明确报错，保留原选择，不悄悄切到另一面。前置固定焦距与前后镜头的照片方向分别处理。
- 应用名称、界面、通知、网页配置标题与源码项目统一为“伴侣”；新安装包命名为 `companion-v0.1.4.apk`。
- 底部固定四个 Tab：“触摸、看世界、电话、设置”。触摸互动独占一页，设置与联系人表单切换 Tab 后保留；其他页各自滚动。已有配置时默认打开触摸页，首次未配置时进入设置页。
- 触摸页使用指定的 [Deepseek Chan](https://codex-pets.net/#/pets/deepseek-chan) 原始动画图集，作者 Dullsaw。待机、轻点、长按和抚摸显示对应动作；离开触摸页或切后台停止动画和未完成手势，减少无用绘制。
- 相机预览只在“看世界”页显示，切换到其他 Tab 后仍由服务在后台待命；不重复切换同一相机输出。保留直接拨号、视觉测试和不显示网页默认口令提示的行为。
- 应用包名、加密存储标识和签名证书保持兼容，可覆盖 0.1.0～0.1.3，保留原有配置与已授予权限。升级后在设置页重新连接 MCP，再开启相机和网页配置。

## 安装与第一次连接

1. 将 `companion-v0.1.4.apk` 传到手机，直接覆盖安装。按系统提示允许当前文件管理器安装此应用。
2. 停止之前的电脑手机相机桥接程序，避免同一个 MCP 接入点重复连接，以及 `self.camera.take_photo` 工具重名。
3. 打开“伴侣”，点击底部“设置”。也可以按下一节从电脑网页配置。
4. 填写 M5 当前绑定智能体的完整 `wss://…` MCP 接入点，保存并连接。不要填写 OTA 地址。
5. 在官方后台确认出现 `self.camera.take_photo`、`phone_camera.get_status`、`self.phone.dial`、`self.touch.get_recent` 四个工具。旧连接未刷新时，在手机停止服务后重新连接，并在后台刷新工具列表。
6. 进入“看世界”，点击“开启相机 · 后台常开”，允许相机权限和通知。再按 M5 对话键说“看看我面前是什么”。相机只在工具调用时抓拍上传一帧，不持续上传视频。

普通版固件仍需按键开始对话。应用不会主动唤醒 M5，也没有接收手机麦克风或传送通话音频的功能。

## 从电脑网页远程配置

1. 手机与电脑连接同一个 Wi-Fi，避免设备隔离的访客网络。
2. 手机进入“设置”，点击“开启网页配置”，屏幕显示 `http://手机IP:8769/#peiban@520`。可长按选择或点击“复制网页配置链接”，将完整链接传给自己的电脑。
3. 在电脑浏览器打开完整链接。也可直接打开 `http://手机IP:8769/`，填写默认口令 `peiban@520`。
4. 页面可以保存 MCP 接入点、视觉 URL、模型、Key、Device-Id、图片模式和电话联系人，查看运行状态，重新连接 MCP，测试视觉模型以及关闭相机。
5. 接入点和 API Key 不会回显；留空保留原值，需要删除时勾选对应的“清空”。修改接入点后会重新连接；其他配置下一次请求生效。测试使用当前表单但不保存。
6. 不用时在手机关闭网页配置。默认口令保持不变；手机 IP 变化后以手机显示地址为准。

此处“远程”指局域网内跨设备配置。没有配置公网端口转发，不支持直接从外网访问；如以后需要跨网络，可另行加入可信 VPN 或经过认证的中继。配置页使用 HTTP，链接和提交内容在局域网明文传输，仅在自己的可信网络使用，勿公开链接。首次开启相机必须在手机授权，网页没有绕过安卓限制来开启相机的入口。

**现在相机由 APK 原生调用，网页仅用于配置。无需 Chrome flags，无需为摄像头安装 HTTPS 证书，小米自带浏览器也可用于配置页。** 安卓首次相机授权若仍提示其他应用叠加层，暂时关闭悬浮球、录屏按钮、聊天气泡或护眼覆盖层后重试。

## 前后摄像头切换

进入底部“看世界”，预览上方会显示“当前选择：后置摄像头”或“前置摄像头”。点击“切换为前置摄像头 / 切换为后置摄像头”即可切换。

- 相机未开启时：只保存选择，不自动启动相机；随后点击“开启相机 · 后台常开”。
- 相机已开启时：自动关闭原镜头，重新打开所选镜头，等待页面状态显示已开启即可继续提问。
- 抓拍识图、镜头启动或切换期间暂时禁止再次切换，避免把上一个镜头的照片当作新镜头画面。切换期间的工具调用返回未就绪提示，不使用旧照片。
- 切换 Tab、锁屏或重新打开应用后继续使用已保存的选择；卸载后重装或清除应用数据后默认后置。
- 如果手机没有前置或后置镜头，切换会明确提示不可用并保留原选择；不会改用相反方向的镜头。

选择前置后，可以对 M5 说“看看我现在的表情”；选择后置后可说“看看我面前是什么”。`phone_camera.get_status` 返回 `camera_facing`（`front` / `back`）和 `camera_switching`，方便智能体了解当前镜头。网页运行状态可看到镜头就绪信息；镜头切换入口在手机“看世界”页。

## 后台常开与锁屏

相机由前台服务托管。在“看世界”页开启后，切到其他 Tab 或离开应用会把预览切换到本机内部图像缓冲，继续相机待命；回到“看世界”页恢复预览。服务持有有时限并按运行状态续期的 CPU 唤醒锁，关闭相机、停止服务或进程退出时释放。通知栏可关闭相机或停止全部服务。

小米 8 的 MIUI 建议手动设置：

- 应用管理 → 伴侣 → 电量 / 省电策略：设为“无限制”或“不限制后台活动”。
- 允许通知；如果提供自启动开关，可允许其后台运行。应用本身不实现开机自启动，也不会在强制停止后偷偷重新开启相机。
- 在最近任务中锁定应用，减少一键清理误关。不同 MIUI 版本的入口名称可能不同。
- 测试锁屏后抓拍，以及切到其他普通应用后抓拍。其他应用打开相机可能抢占硬件，此时需回到伴侣应用重新开启。

安卓和 MIUI 仍可能因电池、温度、权限或进程管理中断服务。程序不能保证无限期保活或绕过系统相机总开关。长期常开会耗电和发热，请先做短时间试用。Android 15 及以上在“仅 MCP / 网页配置、未开相机”的 dataSync 前台服务模式存在系统时限，超时会停止；相机运行时使用 camera 前台服务类型。

## 官方视觉优先

默认“仅官方视觉”，不自动调用自定义服务。开发者权益截图写的是视觉模型“限时免费”，免费期限和额度以官方当时规则为准。

应用支持从 MCP 初始化取得视觉地址与令牌，也支持单次工具调用元数据中的 `me.xiaozhi/vision` 权限。取得后使用官方 `question + file` multipart 协议识图，按需携带 `Client-Id` 和你填写的真实 `Device-Id`。

**账号有开发者视觉权益，不保证外部 MCP 接入点一定会下发该接口。** 如果后台没有下发，工具明确返回缺少官方视觉权限，不会猜测内容，也不会自动改用自定义接口。可结合后台工具调用实际结果确认。

如需备用，明确打开“官方未下发时，允许自定义备用接口”，填写完整 HTTP / HTTPS Chat Completions URL、支持图片的模型名称和 Key。官方权限存在时始终优先官方；官方接口请求失败时也不会悄悄转发到自定义服务。

“测试官方视觉”与“测试自定义视觉”均生成随机图形、颜色与四位数字的测试图，正确答案不写入问题，全部匹配才显示通过。官方测试需要会话已下发权限；仅在工具调用中临时下发的权限无法提前测试。接口返回文字不等于模型看到了图片，一次测试也不代表复杂场景都能识别。自定义测试即使未允许备用也会按你的按钮操作调用该接口，可能计费。

速度模式最长边 768，回答预算 384 tokens；细节模式最长边 1280，预算 700 tokens。“设置”页运行状态显示抓拍压缩、视觉 HTTP 请求、合计耗时和图像大小。接口耗时包括网络、排队和模型处理，不能作为纯推理耗时；不包括小智随后组织回复、合成语音与 M5 播放。

## 拨打电话

在“电话”页设置联系人，每行填写一条 `称呼=电话号码`，点击“保存联系人”，例如：

```text
妈妈=13800138000
自己=13900139000
```

以上为格式示例，请替换为自己的号码。不会自动读取系统通讯录。

先在手机“电话”页点击“授权直接拨号”，允许 Android 电话权限。这是系统的一次性权限授权。之后对 M5 说“请帮我给妈妈打电话”，后台调用 `self.phone.dial`，recipient 填你保存的称呼或完整号码。应用通过 `TelecomManager.placeCall` 直接向电话服务提交呼叫，不弹出伴侣应用确认，也不先打开拨号盘等你点击。“电话”页的“立即拨打（真实呼叫）”同样会真实发起呼叫。

权限未授权或被撤销时，工具返回错误，不保留稍后自动拨出的请求。五秒内重复提交相同号码会被忽略，防止短时间重复呼叫。应用不读取通讯录、短信、通话记录或录音，不监听通话状态；成功仅表示 Android 接受了调用，不能宣称已经拨出或接通。双卡手机建议在系统电话设置中选择默认拨号 SIM；系统可能仍要求选择 SIM、解锁或处理 MIUI 的电话限制。应用无法绕过这些系统要求。通话仍由手机完成，不通过 M5 传输通话音频；挂断请使用手机电话界面。

号码支持数字、开头的 `+` 和常见空格括号短横线；不支持 USSD、分机代码、`tel:` URI 或拨号脚本。工具必须使用用户明确指定的号码或已保存称呼，不能猜测号码。

## 触摸互动

底部“触摸”页独立展示 Deepseek Chan 动画角色。轻点会回应“我在呢”并挥手，按住约 0.6 秒会识别长按，沿角色滑动或来回抚摸会识别抚摸并跳跃，配合短震动与文字反馈。长按达到阈值时记录一次，松手不再重复记为轻点。多指触摸、系统取消手势、切换 Tab 或离开应用会取消未完成的操作。触摸页没有设置表单，可以留在这一页持续互动。

原始图集未经改绘，直接内置 APK，离线也可显示动画，不依赖每次联网加载。图集原尺寸 1536×2288，单帧 192×208。素材来源、作者与校验值见 `app/src/main/assets/deepseek-chan-source.json`；角色美术权利与软件许可分开说明于 `THIRD_PARTY_NOTICES.md`，分享时请一并保留。

触摸后按 M5 对话键说“你感觉到我刚才摸你了吗”或“我刚才抱抱你了”。小智调用 `self.touch.get_recent`，根据真实轻点、长按、抚摸事件回应。需要保持 MCP 已连接，并在官方后台确认新增工具可见。

该工具只读，默认返回最新六条事件，可设置 `limit`（1～32）和 `after_id`（非负整数）。事件带 id、发生时间、距今毫秒、持续时间和滑动距离，按时间顺序返回。事件仅在内存保留五分钟、最多 32 条，读取不清空；`latest_id` 便于后续筛选，`session_id` 改变表示服务重启，应清空旧游标后重新读取。长按的持续时间为触发时已经按住的时间。旧事件过期后返回空列表，不把旧触摸当成当前触摸。

本版感知的是手机应用内触摸区，不能读取锁屏或其他应用里的触摸，也不是 M5 外接硬件触摸传感器。没有温度或可靠的力度测量；“抱抱”只是长按的互动文案。触摸不会主动让 M5 开口，仍需先开始对话让模型读取工具；主动说话需要另行接入设备或后台推送链路。

可在智能体角色说明中补充：

```text
用户要求看眼前场景时，调用 self.camera.take_photo，question 填用户的问题。相机或视觉接口报错时如实告知，不沿用旧图猜测。
用户要求打电话时，调用 self.phone.dial，recipient 填用户明确指定的联系人称呼或号码，不再逐次询问确认。工具成功后只说已向手机系统提交呼叫；不能宣称已经接通。权限或系统报错时如实说明。
用户询问触摸、抚摸、抱抱或触感互动时，调用 self.touch.get_recent。tap 是轻点，long_press 是长按，stroke 是抚摸。依据真实事件温柔回应，注意 age_ms 和 id，避免反复回应同一条旧事件；session_id 改变时清除旧 after_id。没有事件时如实说明，不编造温度或力度，也不要承诺触摸会主动唤醒 M5。
```

## 数据与权限

- 相机照片只在内存中处理，压缩时重编码移除 EXIF，按需发送至官方视觉接口或你明确启用的自定义服务，不存相册或磁盘。
- MCP 接入点、API Key、联系人等使用 Android Keystore AES-GCM 加密后保存到应用私有目录。应用关闭云备份和设备迁移备份；卸载或清除应用数据会失去配置。
- 当前识图文字和耗时在内存显示。网页请求仍需口令鉴权，默认口令为 `peiban@520`，不回显 MCP 密钥或 API Key；已授权页面会显示你保存的电话联系人。
- 相机常驻时有通知和关闭入口。通知被系统隐藏时仍可在应用关闭相机或停止服务。
- 电话权限用于直接呼叫，震动权限用于触摸反馈。触摸事件短暂保存在内存，通过官方 MCP 工具返回给智能体，不存储原始手势轨迹。
- 此版本不包含外部温度传感器、主动发起 M5 语音或手机麦克风功能。

## 构建与验证

源码包包含 Gradle Wrapper，需要 JDK 17 或 21、Android SDK 35 / Build Tools 35.0.0。用 Android Studio 打开项目，或设置好 `ANDROID_HOME` 后执行：

```powershell
.\gradlew.bat testReleaseUnitTest lintRelease assembleRelease
```

`assembleRelease` 生成未签名 APK；本次分发 APK 使用本地单独保管的试用签名证书签名，密钥不在源码或分享文件中。自行编译可用 `assembleDebug` 生成可安装调试包；它与本次分发包签名不同，不能直接覆盖安装。更换签名需先卸载，会清除配置。后续由同一证书签名的升级包可以覆盖。

本机 JVM 测试覆盖 HTTP / HTTPS URL、官方单次视觉权限、MCP 新旧响应格式、前后镜头选择与缺失处理、固定焦距对焦兼容、前后镜头四方向 JPEG 旋转计算、拨号号码与称呼校验、直接调用电话网关与权限拒绝、重复呼叫抑制、系统失败、触摸手势分类与取消、长按不重复、历史容量与过期、读取游标与参数范围、默认网页口令鉴权及重启后复用、密钥不回显与留空保留、随机图结果判定、真实本机 HTTP 模拟视觉请求、官方 multipart 与禁止重定向。电话测试使用模拟网关，不拨打真实号码。前端脚本通过 Node 语法检查，角色图集校验值、尺寸、所用帧的透明通道非空以及 APK 内资源一致性在打包时检查。测试数量、APK 构建和 Android Lint 结果见随包验证记录。JVM 测试不覆盖真实 Android Tab 切换、滚动、动画、震动或 Camera2 硬件行为。

本版本已完成本地构建和自动测试；前后镜头切换、各方向照片与预览、选择保存、相机跨 Tab 和后台抓拍等硬件行为仍需在实际设备上验证。构建过程没有请求真实视觉服务或拨打真实电话。
